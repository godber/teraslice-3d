Passthrough / Environment
Spatial Context
The background canvas surrounding spatial windows. Displays real-world video feed or virtual environment.
Spatial Behavior: Passthrough allows users to maintain full awareness of their physical surroundings while interacting with 3D volumes.
SwiftUI Modifier 
import SwiftUI

// Configure background immersion level
.preferredSurroundingsEffect(.dark) // or .passthrough
2
Volumetric Window Glass
WindowGroup
Translucent spatial window container providing depth, specular highlights, and physical volumetric bounding bounds.
Spatial Behavior: Volumetric windows extend along X, Y, and Z axes to bound 3D spatial content in meters.
App.swift Structure 
WindowGroup(id: "GraphVolume") {
    ContentView()
}
.windowStyle(.volumetric)
.defaultSize(width: 1.0, height: 0.8, depth: 0.8, unit: .meters)
.glassBackgroundEffect()

3D RealityView Content
RealityKit
Interactive 3D spatial scene hosting nodes, connection cylinders, meshes, material shaders, and spatial gestures.
Spatial Behavior: Uses RealityKit entity component system (ECS) to position node spheres and cylinder edges in 3D coordinate space.
RealityView.swift 
RealityView { content in
    let root = Entity()
    // Create nodes and connecting cylinders
    content.add(root)
} update: { content in
    // Update state on hover/selection
}
4
Bottom Ornament
.ornament()
Floating control bar attached relative to window edges without encroaching on 3D volumetric content space.
Spatial Behavior: Ornaments float in front of windows and automatically adjust depth relative to the main window glass.
View Modifier 
.ornament(
    visibility: .visible,
    attachmentAnchor: .bottom,
    contentAlignment: .center
) {
    ControlToolbarView()
        .glassBackgroundEffect()
}

Window Drag Handle
System Affordance
System spatial manipulation pill. Provides the pinch-and-drag target for repositioning or moving windows in 3D physical space.
Spatial Behavior: Managed directly by visionOS. Responds to direct gaze + pinch gestures to translate windows in 6DOF.
System Managed 
// Automatically provided by visionOS
// No custom code required for standard windows
