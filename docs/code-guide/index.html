Chapter 00 · Overview

Reading Teraslice3D-visionOS/

A guided tour of a ~1,600-line native visionOS app: what each file does, which Apple frameworks it leans on, and where to read the official docs for every symbol it touches. Written for someone learning Swift and the visionOS SDKs at the same time.

Swift 6 SwiftUI RealityKit Observation Foundation / URLSession simd Spatial XCTest visionOS 2.0+

What the app is

The repository's main product is a web app: a FastAPI backend that reads Teraslice job configs and serves a pipeline graph, plus a Three.js frontend that draws it in 3D in a browser. Teraslice3D-visionOS/ is a second, native client for the same backend — the graph rendered as actual geometry floating in your room on an Apple Vision Pro, instead of a perspective projection on a flat screen.

It talks to the same four endpoints the web frontend uses (/api/pipeline_graph, /api/jobs, /api/cache/clear, /api/version), runs its own force-directed layout in Swift, and renders spheres (Kafka topics, Elasticsearch indices) connected by cylinders (Teraslice jobs). The design intent is captured in AVP-SPEC.md at the repo root; this guide describes the code as it exists today, and flags the difference in chapter 10.

Two things are worth internalising before you read any Swift:

  • SwiftUI owns the window; RealityKit owns what's inside it. SwiftUI declares a volume (a box of space you can place on a desk), and a single SwiftUI view — RealityView — is the bridge into the 3D scene graph. Everything spatial in this app hangs off that one call.
  • RealityKit units are metres. A sphere of radius: 0.04 is 4 cm across in your living room. That single fact explains most of the odd-looking constants in this codebase (0.40, 0.015, 0.002) and the whole "unitless simulation → physical projection" split in chapter 06.

One trip through the code

The fastest way to hold the app in your head is to follow a single refresh from launch to pixels:

  1. Launch. Teraslice3DApp is annotated @main, so Swift generates the entry point. Its body returns a Scene, and visionOS opens the app's default scene. 02
  2. State construction. @State private var appState = AppState() creates the observable model once and injects it with .environment(appState). AppState.init kicks off a Task that fetches data and then starts a 30-second refresh loop. 03
  3. Fetch + decode. TerasliceAPIClient (an actor) awaits URLSession.data(for:), checks the status code, and hands the bytes to JSONDecoder, which builds PipelineGraph via Codable. Failures silently substitute MockGraphProvider data. 04 05
  4. Observation fires. Assigning appState.graphData invalidates any view that read it. PipelineVolumeView has .onChange(of: appState.graphData), which calls graphEntity.updateGraph(newGraphData). 03 08
  5. Layout. ForceSimulation3D seeds node positions on a Fibonacci sphere and runs 120 iterations of repulsion + springs + gravity in unitless space. 06
  6. Projection. VolumetricProjection measures the resulting bounding box, subtracts the centroid, and scales the longest axis to 0.40 m so the graph always fits the volume regardless of how large the topology grew. 06 07
  7. Geometry. For each node, a NodeEntity gets a sphere MeshResource, a colour-coded SimpleMaterial, a collision shape, and InputTargetComponent + HoverEffectComponent so gaze lights it up. For each link, a LinkEntity cylinder is sized by worker count and rotated to point from source to target. 07
  8. Chrome. A SwiftUI .ornament hangs a glass control bar under the volume: server picker, search field, filter mode, refresh, settings sheet. 08

Conventions

  • Code blocks name their source file and line range; excerpts are lightly trimmed but never rewritten.
  • 🟠 Swift note boxes explain a language feature rather than the app.
  • 🔴 Gap boxes flag code that is written but unused, or behaviour that will surprise you.
  • Framework links point at developer.apple.com and were checked when this guide was written; Apple occasionally reshuffles paths.
🧰
To follow along in Xcode

Open Teraslice3D-visionOS/Teraslice3D.xcodeproj, choose an Apple Vision Pro simulator destination, and run. Start the backend first with cd backend && TERASLICE_URL="…" uv run python -m fastapi dev — the app defaults to http://127.0.0.1:8000 and silently falls back to mock data if nothing answers. Details and caveats in chapter 09.
